# Bella Italia 👑

Веб-платформа для изучения итальянского языка русскоговорящими по программе учебника
**Nuovissimo Progetto italiano 1** (Edilingua) — от нуля (A0) до A2. Тексты, диалоги и упражнения
написаны заново по программе учебника (материалы самих книг в проект не входят).

## Что внутри

- **12 юнитов, 102 урока**: вводный юнит 0 и юниты 1–11 в порядке учебника. В каждом юните есть
  вводный диалог со сквозными героями, уроки грамматики и лексики, урок культуры с текстом и
  фотографиями и самопроверка «Autovalutazione».
- В уроке: **диалог** (озвучка по ролям, перевод по нажатию), **текст**, **правило**, **слова** с
  картинкой, переводом и двойной транскрипцией (русскими буквами с ударением + IPA), **фразы**, **практика**.
- **1561 слово** (~1000 с картинками) и **959 упражнений** 11 типов: выбор, ввод, порядок слов,
  пары, «найди лишнее», верно/неверно, восстановить диалог, текст с пропусками, «найди ошибку»,
  аудирование и диктант.
- **Тесты**: по юниту и свои — трёх уровней сложности; 4 **теста прогресса** (каждые три юнита) с
  разделами «Чтение», «Аудирование», «Грамматика», «Лексика» и «Письмо» (самопроверка по образцу).
- **Карточки** с интервальным повторением (система Лейтнера) и 6 режимов тренировки слов.
- **Игры**: Memory, кроссворд, «Найди слова», «Угадай слово», «Гонка спряжений».
- **Таблицы спряжений** глаголов во всех изученных временах.
- **Озвучка** голосом устройства (Web Speech API), работает и на iPad/iPhone.
- Адаптирована под **iPhone и iPad** (нижняя панель вкладок, безопасные зоны экрана), можно
  добавить на экран «Домой» как приложение.

## Два режима работы

| | Серверный | Статический |
|---|---|---|
| Как запускается | FastAPI + SQLite | любые статические файлы (GitHub Pages и т. п.) |
| Вход | логин и пароль | локальный профиль без пароля |
| Где прогресс | в базе на сервере, доступен с любого устройства | в браузере устройства; можно выгрузить в файл и загрузить на другом |

## Запуск (серверный режим)

Требуются Python 3.11+, Poetry и Node.js 20+.

```bash
poetry install
cd frontend && npm install && npm run build && cd ..
poetry run uvicorn app.main:app --app-dir backend --port 8765
```

Откройте <http://localhost:8765>. FastAPI отдаёт и API (`/api/...`), и собранный фронтенд.
База создаётся автоматически в `data/italy_study.db` (путь — переменная `ITALY_STUDY_DB`).

### Открыть с iPad / iPhone в домашней сети

```bash
poetry run uvicorn app.main:app --app-dir backend --host 0.0.0.0 --port 8765
```

На планшете откройте `http://<IP-компьютера>:8765` (IP можно узнать командой `ipconfig`).
Windows может спросить разрешение для Python в брандмауэре — разрешите для частной сети.

### Переменные окружения

| Переменная | Значение |
|---|---|
| `ITALY_STUDY_DB` | путь к базе, например `sqlite:///C:/path/to/db.sqlite` |
| `ITALY_STUDY_HTTPS=1` | включить, когда сайт работает за HTTPS: cookie получают флаг `Secure`, добавляется HSTS |

## Статический режим (GitHub Pages)

```bash
cd frontend && npm run build:static
```

Готовый сайт — в `frontend/dist-static/`. Пути относительные, поэтому его можно разместить в любой
папке (например, `https://<user>.github.io/<repo>/`).

На GitHub это делается автоматически: workflow `.github/workflows/pages.yml` при каждом push в `main`
запускает тесты, собирает статическую версию и публикует её на GitHub Pages
(в настройках репозитория: *Settings → Pages → Source: GitHub Actions*).

> На iPad откройте сайт в Safari и выберите «Поделиться → На экран „Домой“». Так он работает как
> приложение, а Safari не удаляет сохранённый прогресс. Резервную копию прогресса можно выгрузить
> в профиле.

## Безопасность

- Пароли хешируются **scrypt** (старые хеши PBKDF2 автоматически обновляются при входе).
- Политика паролей: от 8 символов, проверка по списку распространённых и утёкших паролей
  (в том числе с заменами `@→a`, `0→o`), запрет последовательностей и пароля, совпадающего с логином.
  Генератор надёжных фраз из итальянских слов.
- Сессия — случайный токен в cookie `HttpOnly; SameSite=Strict`, в базе хранится только его SHA-256.
  Смена пароля завершает остальные сессии.
- Защита от CSRF (обязательный заголовок + проверка `Origin`), ограничение частоты попыток входа
  и регистрации, строгий Content-Security-Policy и другие защитные заголовки, `no-store` для API.
- Данные каждого пользователя изолированы: все запросы прогресса привязаны к сессии.

> **Про плашку Chrome «Пароль раскрыт»**: Chrome сам сверяет введённый пароль с базами утечек.
> Плашка означает, что *этот пароль* уже есть в публичных утечках (например, `test1234`), а не что
> сайт что-то раскрыл. Теперь такие пароли сайт не принимает при регистрации.

## Разработка

```bash
poetry run uvicorn app.main:app --app-dir backend --port 8765 --reload
cd frontend && npm run dev
```

Vite запустится на <http://localhost:5173> и будет проксировать `/api` на порт 8765.
Документация API — <http://localhost:8765/api/docs>.

После правки контента (`backend/content`) пересоберите курс:

```bash
cd backend && poetry run python -m app.export
```

### Тесты

```bash
poetry run pytest
cd frontend && npm test
```

- **pytest** — загрузка и валидность контента, транскрипция, API, безопасность (политика паролей,
  хеши, cookie, подделка сессий, перебор паролей, CSRF, изоляция пользователей, SQL-инъекции,
  обход каталогов, заголовки).
- **vitest** — каждое упражнение принимает свой правильный ответ и отклоняет неверный, генерация
  тестов и тренировок, интервальное повторение.

## Структура

```
backend/
  app/
    main.py           # FastAPI: авторизация, прогресс, раздача фронтенда
    security.py       # хеширование, сессии, CSRF, ограничение частоты запросов
    passwords.py      # политика паролей
    content.py        # загрузка и валидация учебного контента из YAML
    export.py         # сборка frontend/public/data/course.json
    transcription.py  # транскрипция: IPA и кириллица с ударением
    db.py, config.py
  content/            # юниты, дополнения, тесты прогресса, картинки (см. content/README.md)
frontend/src/
  lib/                # quiz.js (вопросы и проверка), store.js (сервер / localStorage), progress.js …
  pages/, components/ # React-страницы и компоненты
frontend/public/img/  # иллюстрации (e/) и фотографии (p/)
tools/build_images.py # загрузка и подготовка картинок
tests/                # pytest
```

Формат контента описан в [backend/content/README.md](backend/content/README.md).
